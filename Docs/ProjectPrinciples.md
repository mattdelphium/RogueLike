# Development Principles

## Gameplay First

Gameplay always takes priority over architecture.

A playable feature is preferred over a perfect abstraction.

## Keep Systems Simple

Avoid over-engineering.

If a feature only has one implementation, don't create interfaces.

## Data Driven When Useful

Weapons, enemies and upgrades should be configurable from data.

Avoid hardcoded values where possible.

## Small Iterations

Every feature should be added in a playable state before expanding it.

## Commercial Mindset

Every feature should improve:
- Fun
- Replayability
- Retention

If not, reconsider adding it.
